03 / Learning useful memory

The content earns its place.

Writing a file is not enough. We test whether its contents help, and whether learning memory actions matters.

{{SOURCE_INTERVENTION}}

Change the memory. Change the outcome.

Continue from the same post-reset state, but erase or shuffle the saved content. Success falls in every environment.

{{INTERVENTION_CHART}}

Eligible tasks only (counts shown). Shuffled files come from the same environment with matched length. The result identifies a local content effect, not an effect over every task.

{{SOURCE_ABLATION}}

Train the memory actions, too

Removing their actor gradients or restricting the policy to a continuation file reduces average success.

{{ABLATION_CHART}}

Average task success (%) · zero-based bars, maximum 60

No memory-action actor gradients still retains rewards, critic targets and critic learning. “Train + evaluate” and “evaluate” intervene at different stages.

ONE TASK OBJECTIVEDownstream reward → PPO

No extra memory-writing reward.

A single shared policy is trained with fully asynchronous PPO. At a context boundary, the policy writes a bounded continuation file. The environment replaces the context and supplies its path; the policy must read the contents with an ordinary file action. The reset itself is not a policy action.
