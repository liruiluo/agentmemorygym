01 / Start with a familiar skill

Read. Write. Search. Revise.
The model already knows how.

An agent can use ordinary files to keep a plan, save evidence, or leave itself a next step. CAMG-RL builds on these familiar operations to learn useful memory.

A head start,
before training begins.

The base model is already more familiar with ordinary file operations than with dedicated memory tools.

Reinforcement learning turns that familiarity into a practical skill: deciding what to keep and how to use it later.

04 / A skill that travels

Useful memory reaches
beyond its original setting.

New tools.
The same learned memory skill.

The learned policy improves memory through both Claude Code file tools and AgeMem’s dedicated tools—without further training.

The task-execution policy is held fixed; only the policy managing memory changes.

Keep what matters.
Work with a smaller context.

CAMG-RL’s learned file memory, with a 30,720-token active context, outperforms a 262K-context agent using automatic compaction.

Same base model and PPO training budget; different context-management strategies.

Beyond the training environments.

Both the 4B and 9B models carry their gains to software-engineering and machine-learning benchmarks.
